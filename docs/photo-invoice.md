# Приёмка по фото накладной

Экран «Склад» → «Приём поставки» → **«Фото накладной»** (на телефоне открывается камера) или **«Пример фото»**
(`frontend/public/samples/nakladnaya-foto.jpg`, ТОРГ-12 № 4471).

## Как работает

1. Браузер сжимает снимок до 1600 px по длинной стороне (JPEG) и шлёт `POST /api/invoices/recognize` — контракт в `docs/openapi.yaml`.
2. Сервер передаёт фото и **справочник продуктов** модели (`INVOICE_MODEL`, по умолчанию Claude Haiku 5.5 — около $0,0005 за снимок).
   Модель отвечает по JSON-схеме: позиция → `product_id` из справочника (бренд, жирность, фасовка: «Молоко 3,2% 1 л» → молоко),
   количество с пересчётом фасовки («0,5 л × 6» → 3 л), срок, если он напечатан у позиции. `product_id` не из справочника сервер обнуляет.
3. Поставку распознавание **не создаёт**. В предпросмотре по каждой строке: продукт, **принято** (меньше, чем в накладной, — недовоз),
   решение **«Принять» / «Брак»**. Сомнительные строки помечены «проверьте» с причиной.
4. «Принять поставку» шлёт обычный `POST /api/deliveries` только с принятыми строками и количествами. Сроки считает сервер,
   как для любой поставки; позиции без срока берут его из карточки продукта и ждут подтверждения в «Приёмке».
5. Брак и недовоз собираются в **акт расхождений** — текст для поставщика копируется кнопкой.

## Правила

- **Дата документа — не срок годности.** Срок — только напечатанный у позиции «годен до» или «срок хранения».
- **Повтор:** id поставки — от номера и поставщика (оба видны и правятся в предпросмотре; поставщик сравнивается без формы собственности, кавычек и регистра), без даты — её второй снимок может не прочитать. Тот же документ, принятый так же, — `replayed`,
  остатки не меняются; принятый иначе — `delivery_conflict`, второй поставки нет.
- **Ключ** — только `ANTHROPIC_API_KEY` в `.env` сервера. Без ключа на демо-стенде (`DEMO_MODE=true`) отвечает демо-распознаватель:
  образец накладной № 4471 с пометкой «демо-распознавание» в интерфейсе; без ключа и не на демо — `503 not_configured`.
- **Лимит** — `INVOICE_PER_HOUR` распознаваний в скользящий час на экземпляр (по умолчанию 30), сверх — `429` с `Retry-After`.
- Фото до 8 МБ: JPEG, PNG, WebP. В журнал аудита пишется модель, число строк и размер, сам снимок не сохраняется.
