# Дизайн-система SwapOwl

Источник правды — `.ai/frontend-prompt.md`, раздел «Дизайн-система» (визуальный язык линейки Swap «Флагмана», палитра «Свежесть»).

- `swapowl/mockup.html` — макет: логотип, первый экран лендинга, экран склада, язык пометок. Открывается в браузере.
- `swapowl/logo.svg`, `swapowl/logo-inverse.svg` — логотип и его вариант для боковой панели.
- `tokens.css` — значения токенов (цвета, шрифты, сетка).
- `StockSense_App.html` — прежний UI kit: раскладка экранов, состояния и имена компонентов. Его цвета и шрифты не действуют.

## Тёмная тема

Есть светлая (основная, стартовая) и тёмная; переключатель в шапке, выбор помнит браузер. Тёмная палитра — `frontend/src/theme/dark.ts`: переопределяются только цвета (графит с зелёным оттенком, тот же зелёный бренд), размеры и шрифты общие. Пары «текст на фоне» держат 4,5 : 1 (`dark.test.ts`). Боковая панель и логотип на ней одинаковы в обеих темах: текст на панели — `--on-urgency-solid` (белый).
