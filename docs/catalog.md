# Формат техкарт в `PUT /api/catalog`

Техкарты принимаются как в iiko: брутто и нетто, полуфабрикаты. В БД всегда пишутся
развёрнутые до сырья нормы (в базовых единицах продукта); `?dry_run=true` показывает их в
ответе: у каждого блюда в `dishes[].recipe` — `[{product_id, quantity}]`.

## Строка рецепта блюда

Сырьё — одно из трёх:

| Форма | Смысл |
|---|---|
| `{"product_id": "rice", "gross": "150"}` | брутто — столько списывается |
| `{"product_id": "rice", "net": "120", "loss_pct": 20}` | нетто и потери в %; брутто = нетто / (1 − потери/100) |
| `{"product_id": "rice", "quantity": "150"}` | старый формат, то же, что `gross` |

`loss_pct` — число 0…99.99 (не больше двух знаков), допустим только вместе с `net`
(без него потери 0). У всех форм есть необязательный `unit` (`g`, `kg`, `ml`, `l`, `pcs`),
по умолчанию — единица продукта.

Полуфабрикат: `{"prep_id": "sauce", "quantity": "250"}` — сколько полуфабриката нужно, в его
единице (или в `unit` строки). `gross`, `net`, `loss_pct` для него недопустимы.

## Полуфабрикаты

```json
"preps": [{"id": "sauce", "unit": "g", "yield": "1", "yield_unit": "kg",
           "recipe": [{"product_id": "tomato", "net": "480", "loss_pct": 20},
                      {"product_id": "salt", "gross": "100"}]}]
```

`unit` — единица полуфабриката (`g`, `ml`, `pcs`; по умолчанию `g`), `yield` — сколько его
получается из `recipe` (в `yield_unit`, по умолчанию `unit`). В `recipe` — те же строки, что у
блюда; полуфабрикаты могут ссылаться друг на друга. Полуфабрикаты живут только в теле запроса и
в БД не хранятся; продукты в них — из `products` запроса или уже из БД.

## Развёртывание

`domain.ExpandTechcard`: полуфабрикат пересчитывается пропорционально `quantity / yield`,
нормы одного продукта складываются, **округление вверх до базовой единицы один раз** — на
итоговой норме продукта (арифметика точная, без накопления погрешности). Пример выше: 250 г
соуса — 150 г томата и 25 г соли.

## Ошибки (`400`)

- `validation`: цикл между полуфабрикатами, неизвестный `prep_id`, `yield` ≤ 0, одновременно
  `gross`/`net`/`quantity`, `loss_pct` без `net` или вне диапазона, повтор продукта или
  полуфабриката в одном рецепте, развёрнутая норма больше предела количества.
- `unknown_product`: продукта нет ни в запросе, ни в БД.

Ничего не записывается ни при какой ошибке.
