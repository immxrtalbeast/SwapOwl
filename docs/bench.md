# Результат bench: основной алгоритм горячих предложений

Прогон: **200 seed**, 7 суток на seed, правило победителя — `.ai/solution.md`, 2.7 (`simulator.Winner`).

## Итог

- Основной алгоритм: **Bg** (`HOTOFFERS_ALGO=b`, значение по умолчанию в `internal/config/config.go`).
- Решение: ничья, ограничение прошёл только Bg. R нарушил ограничение по отказам (> +1 % заказов к C0) в клетках сценария «скоропорт-попутчик» (`scarce-companion`): M2 при u = 2.0, M1 при u = 1.5 и 2.0.
- Снижение списаний основного алгоритма: к случайным (RND) — **10.1 %**, к ближайшему сроку (C1) — **13.3 %**. Данные для `GET /api/analytics/bench` — `docs/bench.json`.
- В рублях (M2, u = 1.5, сумма по пяти сценариям, неделя): без рекомендаций (C0) списывается 283 122 ₽, с Bg — 254 764 ₽. R списывает ещё меньше (236 975 ₽), но нарушает ограничение по отказам, поэтому основным не становится.
