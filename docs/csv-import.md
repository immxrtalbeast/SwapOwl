# Импорт накладной поставщика из CSV

Экран «Склад» → карточка «Приём поставки» → **«Загрузить накладную (CSV)»**. Рядом — ссылка «Скачать пример»
(`frontend/public/samples/nakladnaya-primer.csv`, Windows-1251, разделитель `;`).

Файл разбирается в браузере. На сервер уходит один `POST /api/deliveries` (контракт — `docs/openapi.yaml`);
сроки считает сервер.

## Формат

- Первая строка — заголовки. Регистр не важен.
- Разделитель `;` или `,` — определяется по строке заголовков. Значения с разделителем внутри берутся в кавычки.
- Кодировка UTF-8 (в т. ч. с BOM) или Windows-1251 — определяется автоматически.
- Пустые строки пропускаются.

## Колонки и синонимы

| Колонка | Обязательна | Синонимы |
|---|---|---|
| товар | да | продукт, наименование, название, product, name, product_id |
| количество | да | кол-во, колво, qty, quantity |
| единица | нет (по умолчанию — единица продукта) | ед, ед. изм., единица измерения, unit |
| годен до | одна из двух | срок годности, годен, expires_on |
| срок, ч | одна из двух | срок ч, срок часов, срок хранения, shelf_life_hours |
| накладная | нет | номер накладной, номер, number, invoice |

- **Товар** — название (без учёта регистра и ё/е) или id продукта. Если не найден, в предпросмотре можно выбрать из списка.
- **Единицы:** г, кг, мл, л, шт (и латинские g, kg, ml, l, pcs). Единица должна быть той же размерности, что у продукта.
- **Количество:** `1,5` и `1.5` равнозначны. Штуки — только целые.
- **Годен до:** `ДД.ММ.ГГГГ` или `ГГГГ-ММ-ДД`. **Срок, ч:** целое 1…87600. Ровно одно из двух на строку.
- **Номер накладной** — из колонки «накладная» (одинаковый во всех строках), иначе из имени файла без расширения.

## Ошибки

Строки с ошибками подсвечены красным с причиной; кнопка «Принять поставку» доступна, только когда ошибок нет.

| Причина | Пример |
|---|---|
| Неизвестный продукт | «Единорог» — выберите продукт из списка |
| Нет срока годности | обе колонки срока пусты |
| Указаны оба срока | заполнены «годен до» и «срок, ч» |
| Неверная дата / срок | `31.02.2026`, `0` |
| Количество не число / ≤ 0 | `много`, `0` |
| Дробные штуки | `1,5 шт` |
| Единица не той размерности | сливки (мл) в килограммах |
| Несколько номеров накладной / номер не указан | уровень файла |

## Повторная загрузка

Id поставки — `csv-` + SHA-256 от номера накладной и позиций (продукт, количество, единица, срок). Тот же файл
с тем же номером даёт тот же id: сервер вернёт `replayed: true`, интерфейс покажет «Эта накладная уже принята»,
остатки не меняются. Изменённое содержимое при том же номере — новый id и новая поставка.
