# Отчёт смены (`#/shift-report`)

Одна печатная страница A4 (кнопка «Печать», `@media print`): продано, списано по причинам, цена стопа, что заказать, прогноз на неделю.

## Источники
- продано / недополучено — `GET /api/orders` (принятые / отклонённые за сутки стенда) × блюда из `GET /api/dishes`;
- списано — `GET /api/analytics/writeoffs?from=D&to=D`;
- чего не хватило — `GET /api/analytics/shortages`;
- что заказать — строки `urgency=now` из `GET /api/supply-suggestions`;
- прогноз — `GET /api/forecast/writeoffs`.

## «Цена стопа»: как считаем
Стоп-лист вычисляется на лету (`internal/api/stoplist.go`), истории его событий нет, поэтому **считаем по отказам**: порции в отклонённых заказах × цена блюда. Это нижняя оценка — недополучено ≈ N ₽ (стоп-часы × темп не посчитать без истории).

## Чего не хватает в API (для тикета)
- `price_minor` у блюда в `GET /api/dishes` (есть только в `PUT /api/catalog`). Пока поля нет, страница показывает порции, а рубли — прочерком; как только поле появится, суммы в ₽ включатся без правок.
- История событий стоп-листа (блюдо, с/по) — для расчёта «часы в стопе × темп × цена».
