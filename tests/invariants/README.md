# tests/invariants

Тринадцать сторожей инвариантов (`.ai/invariants.md`), по одному файлу `invNN_*_test.go`. Меняют только люди: строка `INVARIANT-CHANGE` в описании PR.

Сторожа с пометкой «БД» (1–4, 6–9) собирают и запускают `cmd/api` на отдельной базе в настоящем PostgreSQL; без `INVARIANTS_DATABASE_URL` (или `DATABASE_URL`) они пропускаются с сообщением. Остальные работают на чистом домене.
